Site Capturer

Turn any website into one offline HTML file you can open anywhere.

Site Capturer opens the page in a hidden, minimized window and lets its JavaScript run before saving, so JS-heavy sites are captured too. It then follows same-site links (up to the limits above) and packs everything — text, images, fonts, styles — into one file you'll be asked where to save. No installs beyond this extension, and no internet connection is needed to open the result later.
